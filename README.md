# 졸업 에이전트 · 브라우저 처리 버전

Streamlit이 웹 화면과 공개 라이브러리를 제공하고, PDF 읽기·OCR·성적표 분석·학점 계산과 계획은 이용자 브라우저 안에서 처리합니다. 성적표와 추출한 성적 데이터는 앱에서 Streamlit에 보내지 않도록 만들었습니다. 이용자가 직접 저장하는 JSON 파일에는 학점과 과목 정보와 입력한 영어성적·확인 사항이 포함됩니다. 브라우저 확장 프로그램, 악성코드, 웹서버 소스 변경 등까지 이 구조가 방지하는 것은 아닙니다. 공개 운영 전 네트워크 요청, 접근 권한, 개인정보 처리방침과 법적 요건을 별도 검토해야 합니다.

페이지와 OCR 라이브러리를 내려받는 과정에서는 호스팅 서비스에 접속 기록, IP 주소, 브라우저 정보 등 통상적인 접속 메타데이터가 남을 수 있습니다. 다운로드한 작업 파일은 공유 PC나 백업에 남을 수 있으며 앱의 모두 지우기 버튼으로 삭제되지 않습니다. 저장소에 실제 성적표, 저장한 JSON 또는 개인정보를 올리지 마세요. 이 설명은 현재 소스에 대한 것이며, 호스팅 환경 또는 소스가 바뀌면 다시 확인해야 합니다.

## 실행 및 Streamlit Community Cloud 배포

Python 3.12에서 `pip install -r requirements.txt` 후 `streamlit run app.py`를 실행합니다. Streamlit Community Cloud에는 저장소의 `app.py`를 지정하고 Python 3.12를 선택합니다. 저장소에 `app.py`, `bootstrap_vendor.py`, `requirements.txt`, `.streamlit/config.toml`, `client/`, `static/`이 있어야 합니다. 파일 이름과 폴더를 바꾸지 마세요. 무료 배포에 API 키가 필요하지 않습니다. 공개 라이브러리가 없는 서버에서는 최초 실행 시 npm과 jsDelivr에서 지정된 버전을 내려받고 해시를 검증합니다. 이 요청에는 학생 정보가 포함되지 않으며 서버가 외부 패키지 서버에 접근할 수 있어야 합니다.

## 기능과 한계

- 텍스트 또는 스캔 PDF를 브라우저에서 분석합니다. 스캔본은 기기의 성능과 품질에 따라 느리거나 잘못 읽힙니다. 반드시 원본과 대조해야 합니다.
- 경영학 2018~2026학번과 기술경영의 선택한 이수기준을 사용해 이수 학점 및 필수영역을 잠정 비교합니다. 여러 단으로 배치된 텍스트 성적표는 단과 줄바꿈을 복원하고 수강 학기를 읽어 공개 수강목록과 과목명을 대조합니다. 같은 학기에 같은 이름과 번호가 하나씩 일치하는 경우 우선 대조하며, 학기 자료가 없는 경우에는 다른 공개 목록의 정확히 일치하는 고유 번호를 참고합니다. 목록은 전체 교과목이나 이수 인정, 최신 개설 여부를 보장하지 않습니다. 같은 학기에 동일 명칭에 여러 번호가 있거나 일치 과목이 없는 경우, 학교 수강 이력에서 확인해야 합니다.
- 전필·전선은 경영학, 교양은 교양으로 잠정 배정합니다. 기술경영이 명시된 증명서의 연전도 기술경영으로 잠정 배정합니다. 일선·중복인정은 자동 인정하지 않으며 각 행에서 수정합니다. 재수강 번호가 반복되면 모두 제외하여 직접 반영 여부를 선택하게 합니다.
- 같은 이름의 과목이 필수 목록에 있으면 다른 번호 또는 번호 미확인도 이수로 잠정 계산하고 전공주임 별도 인정 필요로 표시합니다. 실제 인정을 보장하지 않습니다. 번호가 성적표에 없어 추정한 경우도 확인이 필요합니다. 한 과목을 기술경영의 여러 필수 영역에 반복 산입하지 않습니다.
- 추가 졸업요건 탭에서 졸업 신청 학기, 등록 횟수, 영어강좌 수와 시험별 점수 및 유효기간을 입력해 비교합니다. 교양 영역, 평점, 통계학 이수, 중복인정과 졸업논문은 직접 확인한 결과를 표시합니다.
- 부족한 필수영역과 학점은 다음 정규학기부터 사용자가 지정한 총학점·전공학점 한도 내에 배정합니다. 실제 강좌 개설, 선수과목, 시간표, 교양 세부 기준, 논문 및 학교의 최종 승인 여부는 자동 확인하지 않습니다. 생성된 과목 후보는 수강 가능이나 졸업 충족을 보장하지 않습니다.
- 자유 대화형 AI는 제공하지 않습니다. 목표 평점 계산을 제공합니다.

공식 자료와 적용 내용은 `학교_기준_정리.md`를 참고하세요. 해당 파일과 이 README에는 이용자 성적표가 포함되지 않습니다.

## 개발 검사

`node test_browser_engine.js`는 학점 계산, 재수강, 학기별 한도, PDF 텍스트 파싱을 검증합니다. 실제 학생의 성적표는 테스트 파일에 넣거나 저장소에 올리지 마세요.
